# Partition 그룹 비교 통합 검증

기존 전체 승인 범위에서 exact owned 그룹 쌍의 동일성 비교만 재사용한다. 공개 API, transport, 수학 kernel, 기본/전역 work 한도와 charge는 변경하지 않았다. 호출자 객체·shallow freeze·그룹 교체는 재검증한다.

같은 고정 archive를 Node20/22/24에 실제 설치하고 각 partition 소비자3개·strict 타입·문서 예제·optional peers·6개 browser entry를 검증했다. 별도1000개 전체 cell의4시점과9개 rebase 시점13000개 검증 및 offline 일치를 확인했다. animation 소유712개와 focused44개는 중복 범위로 합산하지 않는다. 원10000개 기본 guard는 여전히 거부하며 이전 단발 속도 관측은 P95/SLO 자격이 아니다.

Source는 incoming4e399와 byte-identical이므로 변경 없는 owner의 기존100/93.94/100 coverage 증거를 재사용한다. 전체 coverage를 새로 실행했다고 주장하지 않는다. Node20/24 최초 packed1,788,824 거부 로그를 보존하고 최소1,788,900 ceiling, 실제 unpacked8,053,787에 최소8,053,800 ceiling을 적용하고 다른 guard는 유지한다. 최종 세부 결과와 raw bytes/hash는 qualification.json 및 gzip evidence가 소유한다.
