# 실제 설치 runtime의 정상 발견 소유자

30종 family의 package 소비자를 정상 발견되는 `test/contracts/installed-native-families.test.js`에 연결했다. 이 시험은 canonical package를 임시 디렉터리에 설치하고 기존 testNodeConsumer의 실제384개 bare-import 사례를 모두 실행한다. 각 family는 구체적 실행 receipt ID와 통과를 요구하며 다른 사례의 실패도 전체 실패로 전파한다. 원래 full package consumer 경로와 기본 동작은 보존한다.

같은 a2c8612d archive의 명시 입력과 default pack/install 경로 모두384사례 및30family subtest가 통과했다. 네 경로 방법은 실제 four-route-player-lifecycle 사례가 각각 생성·상태·hit·interruption·revision·codec을 실행한다. Generic export/AST 검사가 이 근거를 대신하지 않는다. 각 사례 실행 뒤 receipt를 써 중간 실패의 진행 상황을 남긴다.
