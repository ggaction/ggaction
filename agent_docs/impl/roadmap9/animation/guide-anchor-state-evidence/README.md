  Node20/22/24의 새 순수·native 14개씩으로 검증했다. 변경 없는 전체 회귀를 반복하지 않았다.

  각 canonical critical floor를 그대로 적용했다. 원 전체 실행과 후행 집중 실행은 별도 로그다.
- 경계·발견·coverage policy·package·documentation truth·architecture path 40/40가 통과했다.
  기존 source312026112를 이용한 세 native case의 전체 serialized program/trace가 정확히 같다.

  완료 상태와 동일 archive hash는 `summary.json` 및 각 `installed*.json`에 기록한다.

## 수치와 안전 경계

최초 literal 검사의 ULP 기대식 및 오류 문자열, native fixture의 overlap/graphic ID/Canvas config
오류는 수리 전 로그에 보존했다. 최종 검사는 독립 수학 tolerance와 실제 native owner를 대조한다.
Cartesian title의 음수 offset은 원 계약대로 허용한다. Inferred/label-relative title clearance는
미리 준비한 ink dependency가 없으므로 `guide-layout`으로 남긴다.

Band range `[0.2857142857142857,100.95238095238096]`에서
`[1.5714285714285714,105.23809523809524]`로 0.37 시점에 이동하면 양 끝에서 하나였던
`a.end + b.start`가 native 연산상 1 ULP로 갈라진다. 최초 탐색에서 throw를 확인했고,
정확 endpoint는 유지하면서 그 중간만 `guide-layout` fade하는 literal 회귀로 닫았다.
Pixel 허용오차를 추가하거나 어느 edge를 선택하지 않았다.

Parallel source의 domain×tick 누적 work가 10M을 넘으면 range getter/매핑 이전에 거부한다.
순수 입력은 own-data/closed-shape 검증을 거치며, 값·배열·프로그램과 trace를 변경하지 않는다.
