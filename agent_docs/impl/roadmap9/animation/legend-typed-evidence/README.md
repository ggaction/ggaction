# Exact native gradient 범례 전환

Source `71d2eda28`은 [remainingApproval](../../AUTHORIZATION.json#remainingApproval) 아래
기존6개 공개 animation API에 exact-value color/stroke gradient를 연결했다. Native raw tick,
명시 offset·single-edge block·font query closure·scale/domain을 준비하고 기존 layout/strip
owner로 현재 geometry를 만든다. Key는 raw value/title/정규화60segment 역할이며 표시 문자열을
identity로 쓰지 않는다. Guide manifest는@3, 이 branch의 전체 transition은@2다. Root timeline@3은
후속 합산에서 보존하며 shared source 변경은 승인된 sampler import와 rect admission뿐이다.

11개 최종 범례 회귀는 log literal, 네 edge·hard-break title, color/stroke·temporal, mutable 입력,
exact font profile, unknown/corrupt proof, 재기준·strict offline을 검증했다. 전체 animation360과
native guide/legend1120이 통과했다. 새4owner coverage99.48/97.71/100, source 경계32 및
package/sharding17도 통과했다. 실제5dataset의 같은 원행·단위로7recipe(35쌍)를 canonical
realistic runner에서 실행했다. Canvas/SVG/PNG/PDF·실제 browser 7개는 새 rectangle gradient를
같은 frame으로 검증하며 PDF는 vector를 유지한다. 대표 PNG를 직접 확인했다.
