## 승인 근거

Gate 상태: `approved`. 사용자는 이 프로젝트 범위에서 “지금까지 모든 질문,
앞으로 할 모든 질문 승인함”이라고 명시했으며, 번역 중 필요한 라이브러리와
파이프라인 수정을 계속 수행하도록 지시했다. 그 범위 안의 아래 단일 선택을
구체화해 같은 승인을 재사용한다. 새 차트 유형이나 렌더링 primitive는 추가하지
않는다. 기존 두 줄 부제의 글자·크기·10px 줄 간격이 목표이며, 이미지 판독 대신
실제 SVG 글자 좌표와 수치 검증을 사용하라는 사용자 지시를 따른다.

## 문제와 공개 계약

13px 한 줄 제목과 8px 두 줄 부제에서, 기본 부제 간격은 9.6px이다. 공통
`lineHeight: 10`은 제목 글자 크기 검증에 걸려 부제만 10px로 만들 수 없다.

기존 `createTitle`과 `editTitle`에 `subtitleLineHeight?: number`만 추가한다.

- 유한한 수이며 저장된 부제 스타일의 `fontSize` 이상이어야 한다. 숨겨진 부제도
  같은 검증을 적용해 제거·복원과 스타일 편집의 일관성을 유지한다.
- 부제 간격은 명시/저장된 `subtitleLineHeight`, 공통 `lineHeight`, 부제 글자 크기
  × 1.2 순서로 결정한다. 제목 간격과 기존 공통 옵션 검증은 그대로다.
- 명시적 줄바꿈에도 적용하므로 `maxWidth`가 필요 없다.
- 생성 시 생략하면 새 저장 키가 없고, 편집 시 생략하면 기존 값을 보존한다.
  새 reset 어휘는 추가하지 않는다.
- 기존 title materialization config에만 저장한다. semantic text·액션 수·renderer
  경계·package entry는 바뀌지 않는다.
- 부제 제거 시 설정을 보존하고 전체 제목 제거 시 함께 제거한다. 모든 기존
  Canvas 경계·guide 충돌·immutable 실패와 재배치 규칙을 유지한다.

## 검증 목표

기존 생략/공통 간격의 완전 동일 출력, 13px/8px 부제 10px, hard/soft/blank
line, 네 방향, Canvas/facet 재배치, 저장·복원, 타입, 잘못된 값·부제 스타일
충돌의 원자적 실패, 브라우저의 실제 글자 좌표를 검증한다. 이전에 동결한
번역 패키지와 기록은 수정하지 않으며, 후보 패키지는 별도 자격 검증 후 채택한다.
공개 릴리즈는 최신 사용자 지시에 따라 1,387개 차트 완료 후 진행한다.
이전 1,500개 계획은 축소되었으며 기존 승인·실행 기록은 보존한다.

## 통합 전 검증 기록

- 일반 테스트 5,691개, 설치된 패키지의 7개 소비자 범주(Node·타입·PNG/PDF 포함), 생성 옵션 인벤토리 7개가 통과했다.
- 실제 브라우저 Canvas/SVG 간격과 제목 관련 40개 테스트, 타입 계약, 문서 153개도 통과했다.
- 새 설치 소비자 사례의 manifest 누락과 파생 인벤토리 개수 누락은 각각 해당 목록만 수정한 뒤 재검증했다. 런타임 코드 변경이나 한도 완화는 없었다.
- 로컬 realistic guide 전체 검사는 저장 공간 감시기가 중단하여 미완료다. 통합 revision의 전체 CI(coverage·realistic 포함) 통과를 별도로 요구한다.
- 기존 0.0.24 준비 기록은 보존했고, 이 새 소스 체크포인트를 clean revision으로 동일 버전 재준비한다. 공개 배포는 수행하지 않는다.
