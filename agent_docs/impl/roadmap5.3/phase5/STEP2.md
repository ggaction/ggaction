## 실행 순서

1. Official client transport로 실제 child process를 spawn해 initialize, resource listing/template listing, exact read와 search를 검증한다.
2. `npm pack` 결과만 새 temporary consumer에 설치하고 exposed bin과 packaged knowledge completeness를 검증한다.
3. Blank/oversized query, invalid limit, malformed/unknown IDs와 non-contract URI를 실패시킨다.
4. Package source/import graph와 server registration을 검사해 HTTP/network, arbitrary path, eval/import, chart/render tool이 없음을 증명한다.
5. Root/basic/svg production bundles가 기존 ceiling을 유지하고 MCP SDK/knowledge string을 포함하지 않는지 검사한다.
6. Condition C adapter가 local MCP search/read만 사용하고 A/B와 동일 evaluation envelope를 유지하는 mock/dry flow를 실행한다.

## 완료 기준

- Clean consumer stdio protocol과 all declared resources/tool이 통과한다.
- Package artifact는 허용된 bounded files만 포함하고 executable mode를 보존한다.
- Browser bundle과 chart import graph가 MCP runtime dependency에서 격리된다.
- 실제 model/API call과 spend는 0이다.
