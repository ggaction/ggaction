## 구현 결과

`knowledge/recipes/*.json` 33개가 task intent, 선택 기준, 입력, ordered action role, 대안, 함정, executable example와
canonical docs route를 소유한다. 기존 public recipe/chart program을 먼저 재사용하고, 기존 완성 program이 직접 다루지
않던 guide/layout, lifecycle, selection과 extension workflow만 focused registry로 보충했다.

`scripts/recipe-knowledge.js`와 combined knowledge generator는 다음 오류를 차단한다.

- Unknown/duplicate recipe/action/step/role와 깨진 docs file/anchor 또는 example export
- Title/intent만 반복하는 선택 guidance와 schema에 맞지 않는 input/alternative/pitfall
- 실행 실패, `ChartProgram`이 아닌 example과 primary action trace 누락
- 173-action missing/duplicate coverage, 분류 role evidence 누락과 ordinary action의 빈 backlink
- Recipe step, coverage source와 action `recipeIds` 사이의 양방향 불일치
- Recipe/action source hash 및 `knowledge/index.json`, public action/recipe JSON의 generated drift

Generated `knowledge/index.json`은 action 이름과 recipe ID 순으로 stable sort된 action, recipe와 coverage를 함께 제공한다.
`docs/llms-recipes.json`은 같은 recipe/coverage의 public view이고 작은 Markdown router는 이 complete structured document로
연결한다. Public API, action behavior, declarations, package exports와 renderer 경계는 변경하지 않았다.
