# Roadmap 5 Phase 2 — Semantic Category Ordering

## 목표

Nominal/ordinal Cartesian x/y category order를 semantic assignment로 저장하고 scale, mark와 connected guide를
함께 rematerialize하는 `orderCategories`와 automatic first-appearance order를 복원하는
`removeCategoryOrder` complete vertical slice를 구현한다.
