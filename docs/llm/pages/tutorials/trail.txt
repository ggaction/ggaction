# Show width along a series

Keep position and sample width separate. These two signals have constant vertical
positions while the first ribbon widens and the second narrows.

## Example with real data

`createGapminderLifeTrails` builds this chart from real data. It receives the rows of `data/gapminder.json` (Gapminder).
Draw the returned program with `render` in a browser or `renderToPNG` in Node.

```javascript
import { chart } from "ggaction";

const LARGEST = ["China", "India", "United States", "Indonesia", "Brazil", "Pakistan", "Bangladesh", "Nigeria"];

// Gapminder life expectancy for the eight most populous countries in 2005.
export function createGapminderLifeTrails(gapminder) {
  const rows = gapminder
    .filter(row => LARGEST.includes(row.country))
    .map(row => ({
      id: `${row.country}/${row.year}`,
      country: row.country,
      year: row.year,
      lifeExpectancy: row.life_expect,
      // Ribbon width in pixels grows with the square root of population.
      width: 1 + 0.6 * Math.sqrt(row.pop / 1e6)
    }));

  return chart()
    .createCanvas({ width: 900, height: 520, margin: { top: 80, right: 160, bottom: 60, left: 70 } })
    .createData({ id: "trajectories", keyField: "id", values: rows })
    .createTrailPlot({
      x: { field: "year", scale: { zero: false, nice: false } },
      y: { field: "lifeExpectancy", scale: { zero: false, domain: [20, 80] } },
      width: "width",
      groupBy: "country",
      color: {
        field: "country",
        scale: {
          domain: LARGEST,
          range: ["#dc2626", "#ea580c", "#2563eb", "#16a34a", "#0d9488", "#7c3aed", "#db2777", "#ca8a04"]
        }
      },
      body: { opacity: 0.75 },
      guides: {
        axes: {
          x: { title: { text: "Year" }, ticksAndLabels: { labels: { format: ".0f" } } },
          y: { title: { text: "Life expectancy (years)" } }
        },
        legend: { title: "Country" },
        grid: { horizontal: true, vertical: false }
      }
    })
    .createTitle({
      text: "Fifty years of longer lives",
      subtitle: "Life expectancy 1955–2005 · ribbon width follows population · China dips during the 1959–61 famine"
    });
}
```

## A small worked example

```js
import { chart } from "ggaction";

const signals = chart()
  .createCanvas({ width: 420, height: 240, margin: 40, background: "#ffffff" })
  .createData({ id: "signals", keyField: "id", values: [
    { id: "a0", time: 0, signal: 7, width: 8, channel: "A" },
    { id: "a1", time: 10, signal: 7, width: 32, channel: "A" },
    { id: "b0", time: 0, signal: 3, width: 28, channel: "B" },
    { id: "b1", time: 10, signal: 3, width: 12, channel: "B" }
  ] })
  .createTrailPlot({ id: "trail", x: { field: "time", scale: { domain: [0, 10] } },
    y: { field: "signal", scale: { domain: [0, 10] } }, width: "width", groupBy: "channel",
    color: { field: "channel", scale: { domain: ["A", "B"], range: ["#2563eb", "#0d9488"] } }, guides: false });

const constant = signals.editTrailPlot({ width: 18 });
const selected = signals.selectMarks({ id: "channel-a", target: "trail", field: "channel", op: "eq", value: "A" })
  .highlightMarks({ selection: "channel-a", fill: "#dc2626" });
```

The widths 8 and 32 are logical pixels at the endpoints, with linear width between
them. Resizing the Canvas changes position spacing while retaining those screen
widths. A computed dataset can supply a calculated width field without changing the
original measurements. See [Trail options](../../../api/trail/) for curves, missing
samples, Polar paths, labels, clipping and effects.
