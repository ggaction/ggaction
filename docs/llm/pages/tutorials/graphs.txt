# Draw an observed network

Create two node rows and one observed directed edge. A fixed layout determines positions; the plot adds circles, an arrow and readable labels. This is the canonical graph example's action flow.

> **Runnable complete example.** Use the Getting Started browser module setup with a canvas whose id is chart.

```javascript
import { chart, render } from "ggaction";

const program = chart()
  .createCanvas({
    "width": 300,
    "height": 240,
    "margin": 0,
    "background": "#ffffff"
  })
  .createData({
    "id": "nodes",
    "values": [
      {
        "id": "A"
      },
      {
        "id": "B"
      }
    ],
    "keyField": "id"
  })
  .createData({
    "id": "edges",
    "values": [
      {
        "source": "A",
        "target": "B"
      }
    ]
  })
  .createGraphData({
    "id": "network",
    "nodes": "nodes",
    "edges": "edges",
    "nodeKey": "id",
    "source": "source",
    "target": "target",
    "directed": true,
    "selfLoops": true
  })
  .layoutGraph({
    "id": "positions",
    "graph": "network",
    "method": "fixed",
    "options": {
      "positions": [
        {
          "key": "A",
          "x": 60,
          "y": 120
        },
        {
          "key": "B",
          "x": 240,
          "y": 120
        }
      ]
    }
  })
  .createGraphPlot({
    "id": "networkPlot",
    "layout": "positions",
    "origin": [
      0,
      0
    ],
    "nodes": {
      "radius": 10
    },
    "edges": {
      "stroke": "#64748b",
      "strokeWidth": 2,
      "parallelGap": 90,
      "loopRadius": 32
    },
    "labels": {
      "offset": [
        0,
        24
      ],
      "fontSize": 14
    }
  });
render(program, document.querySelector("#chart").getContext("2d"));
```

## Example with real data

`createCountrySimilarityNetwork` builds this chart from real data. It receives the rows of `data/gapminder.json` (Gapminder).
Draw the returned program with `render` in a browser or `renderToPNG` in Node.

```javascript
import { chart } from "ggaction";

// Gapminder's six regional clusters, in cluster-number order.
const REGIONS = ["South Asia", "Europe & Central Asia", "Sub-Saharan Africa", "Americas",
  "East Asia & Pacific", "Middle East & North Africa"];
const COLORS = ["#f59e0b", "#3b82f6", "#10b981", "#ef4444", "#8b5cf6", "#ec4899"];

// Each country links to its three nearest neighbors in standardized
// (life expectancy, fertility) space for 2005.
export function createCountrySimilarityNetwork(gapminder) {
  const countries = gapminder
    .filter(row => row.year === 2005)
    .map(row => ({
      country: row.country,
      region: REGIONS[row.cluster],
      lifeExpectancy: row.life_expect,
      fertility: row.fertility
    }));

  return chart()
    .createCanvas({ width: 900, height: 640, margin: { top: 80, right: 200, bottom: 20, left: 20 } })
    .createData({ id: "countries", keyField: "country", values: countries })
    .createInferredGraphData({
      id: "similar",
      data: "countries",
      nodeKey: "country",
      ruleId: "three-nearest",
      rule: "knn",
      features: ["lifeExpectancy", "fertility"],
      metric: "euclidean",
      preprocess: "standardize",
      attributes: ["region"],
      options: { k: 3, symmetrize: "union" }
    })
    .layoutGraph({ id: "placement", graph: "similar", method: "force", options: { seed: 7, iterations: 400, linkDistance: 70, collisionRadius: 14 } })
    .createGraphPlot({
      nodes: {
        radius: 6,
        stroke: "#ffffff",
        strokeWidth: 1,
        overrides: countries.map(row => ({ key: row.country, fill: COLORS[REGIONS.indexOf(row.region)] }))
      },
      edges: { stroke: "#cbd5e1", strokeWidth: 1 },
      labels: { fontSize: 9, fill: "#334155" }
    })
    .createTitle({
      text: "Countries with similar health and family size, 2005",
      subtitle: "Each country links to its 3 nearest neighbors in life expectancy and fertility · color: region"
    });
}
```

## Preserve separate connections

The parallel example contains two observed edges with the same endpoints. Both survive as distinct paths and selections. The self-loop example retains an edge whose endpoints name the same node. Neither view infers new connections from position.

## Revise the view

Continue from `program` with `program.editGraphPlot({target:"networkPlot",nodes:{radius:14}})` to change node size. Use `editLayout` to change fixed positions, or create a separate circular/force layout and explicitly rebind the plot. Source revisions update dependent layouts and plots together. The original program remains available.

See [Graph plots](../../../api/graphs/) for full defaults, typed overrides, label attributes, selection and output behavior.
