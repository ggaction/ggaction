# Show contributions and totals

Declare each row's role so its effect on the running balance is explicit.
Positive and negative contributions share the same ordered scale; totals start
at zero without changing the balance.

## Example with real data

`createTemperatureWaterfall` builds this chart from real data. It receives the rows of `data/showcase/global-temperatures.csv` (NASA GISTEMP, public domain) with numeric fields parsed.
Draw the returned program with `render` in a browser or `renderToPNG` in Node.

```javascript
import { chart } from "ggaction";

// NASA GISTEMP annual (J-D) anomalies: the 2013 level plus each later year's change.
export function createTemperatureWaterfall(temperatures) {
  const years = temperatures
    .filter(row => row.Year >= 2013 && row.Year <= 2022 && Number.isFinite(row["J-D"]))
    .map(row => ({ year: row.Year, anomaly: row["J-D"] }));
  const steps = years.map((row, index) => ({
    id: String(row.year),
    stage: index === 0 ? "2013 level" : String(row.year),
    role: "delta",
    value: index === 0 ? row.anomaly : Number((row.anomaly - years[index - 1].anomaly).toFixed(2))
  }));
  steps.push({ id: "total", stage: "2022 level", role: "total" });

  return chart()
    .createCanvas({ width: 900, height: 460, margin: { top: 80, right: 40, bottom: 60, left: 70 } })
    .createData({ id: "steps", keyField: "id", values: steps })
    .createWaterfallPlot({
      x: "stage",
      role: "role",
      value: "value",
      width: { band: 0.65 },
      // Leave room above the highest running total for its label.
      yScale: { domain: [0, 1.2] },
      labels: { content: "value", format: ".2f", fontSize: 12 },
      guides: {
        axes: { x: { title: false }, y: { title: { text: "Temperature anomaly (°C)" } } },
        legend: false,
        grid: { horizontal: true, vertical: false }
      }
    })
    .createTitle({
      text: "How the global temperature anomaly moved, 2013–2022",
      subtitle: "Green bars warm the running total, red bars cool it · NASA GISTEMP annual means"
    });
}
```

## A small worked example

```js
import { chart } from "ggaction";

const contributions = chart()
  .createCanvas({ width: 500, height: 320, margin: 40, background: "#ffffff" })
  .createData({ id: "contributions", keyField: "id", values: [
    { id: "a", stage: "Revenue", role: "delta", value: 5 },
    { id: "b", stage: "Cost", role: "delta", value: -2 },
    { id: "c", stage: "Subtotal", role: "subtotal" },
    { id: "d", stage: "Other", role: "delta", value: 4 },
    { id: "e", stage: "Total", role: "total" }
  ] })
  .createWaterfallPlot({ id: "waterfall", x: "stage", role: "role", value: "value",
    width: { pixels: 48 }, yScale: { domain: [0, 10] }, guides: false });

const labeled = contributions.editWaterfallPlot({ target: "waterfall", labels: {} });
const selected = labeled.selectMarks({ id: "cost", target: "waterfall",
  field: "id", op: "eq", value: "b" })
  .highlightMarks({ selection: "cost", stroke: "#1d4ed8", strokeWidth: 2 });
```

The balance moves from 5 to 3, stays at 3 for the subtotal, then rises to 7.
The final total is 7. Its value is derived from the explicit contribution rows;
the total row intentionally has no `value` property.

A source revision recalculates the full sequence while preserving keyed stage
identity. Bar, connector and label stay together during selection and hit
testing. See [Waterfall options](../../../api/waterfall/) for reset fields, color
scales, effects, clipping and scoped edits.
