# Draw conserved flows

Start with a node table and an edge table whose values have one shared unit.
A flow graph validates the endpoints and values, a layout stores their positions,
and two marks draw the ribbons and nodes.

## Example with real data

`createPenguinSankey` builds this chart from real data. It receives the rows of `data/showcase/penguins.csv` (palmerpenguins, CC0) with numbers parsed and `NA` read as `null`.
Draw the returned program with `render` in a browser or `renderToPNG` in Node.

```javascript
import { chart } from "ggaction";

const SPECIES_COLORS = { Adelie: "#f97316", Chinstrap: "#a855f7", Gentoo: "#0d9488" };

// Every penguin flows from its species to the island it was measured on, then to its sex.
export function createPenguinSankey(penguins) {
  const nodes = new Map();
  const links = new Map();
  const node = (id, name, fill) => {
    if (!nodes.has(id)) nodes.set(id, { id, name, fill });
  };
  const link = (from, to, fill) => {
    const id = `${from}→${to}`;
    if (!links.has(id)) links.set(id, { id, from, to, count: 0, fill });
    links.get(id).count += 1;
  };
  for (const penguin of penguins) {
    const species = `species:${penguin.species}`;
    const island = `island:${penguin.island}`;
    const sex = `sex:${penguin.sex ?? "unrecorded"}`;
    const fill = SPECIES_COLORS[penguin.species];
    node(species, penguin.species, fill);
    node(island, `${penguin.island} Island`, "#64748b");
    node(sex, penguin.sex ? penguin.sex[0].toUpperCase() + penguin.sex.slice(1) : "Not recorded", "#94a3b8");
    link(species, island, fill);
    link(island, sex, "#94a3b8");
  }
  const nodeRows = [...nodes.values()];
  const linkRows = [...links.values()];

  return chart()
    .createCanvas({ width: 900, height: 520, margin: { top: 80, right: 120, bottom: 30, left: 100 } })
    .createData({ id: "nodes", keyField: "id", values: nodeRows })
    .createData({ id: "links", keyField: "id", values: linkRows })
    .createFlowData({
      id: "flow",
      nodes: "nodes",
      edges: "links",
      nodeKey: "id",
      edgeKey: "id",
      source: "from",
      target: "to",
      value: "count",
      attributes: ["name"]
    })
    .layoutFlow({
      id: "layout",
      method: "dag",
      options: { width: 680, height: 410, nodeWidth: 16, nodePadding: 22, order: "barycentric", iterations: 16 }
    })
    .createFlowLinks({
      links: { opacity: 0.45, overrides: linkRows.map(row => ({ key: row.id, fill: row.fill })) }
    })
    .createFlowNodes({
      clip: false,
      nodes: { overrides: nodeRows.map(row => ({ key: row.id, fill: row.fill })) },
      labels: { content: { field: "name" }, fontSize: 13, fontWeight: 600, outline: { color: "#ffffff", width: 3 } }
    })
    .createTitle({
      text: "344 Palmer penguins by species, island and sex",
      subtitle: "Gentoo live only on Biscoe and Chinstrap only on Dream · link width is the number of birds"
    });
}
```

## A small worked example

This runnable Full example sends six units from one source and four from another
to a total of ten. The layout preserves a common thickness scale.

> **Runnable complete example.** Import the Full ggaction package; the example declares its own node and edge tables.

```javascript
import { chart } from "ggaction";

const program = chart()
  .createCanvas({
    "width": 640,
    "height": 500,
    "margin": {
      "left": 40,
      "right": 40,
      "top": 80,
      "bottom": 40
    },
    "background": "#ffffff"
  })
  .createData({
    "id": "nodes",
    "values": [
      {
        "id": "Supply A"
      },
      {
        "id": "Supply B"
      },
      {
        "id": "Total"
      }
    ],
    "keyField": "id"
  })
  .createData({
    "id": "edges",
    "values": [
      {
        "id": "a",
        "from": "Supply A",
        "to": "Total",
        "value": 6
      },
      {
        "id": "b",
        "from": "Supply B",
        "to": "Total",
        "value": 4
      }
    ],
    "keyField": "id"
  })
  .createFlowData({
    "id": "flow",
    "nodes": "nodes",
    "edges": "edges",
    "nodeKey": "id",
    "source": "from",
    "target": "to",
    "edgeKey": "id",
    "value": "value",
    "balance": "strict"
  })
  .layoutFlow({
    "id": "layout",
    "method": "dag",
    "options": {
      "width": 400,
      "height": 240,
      "nodeWidth": 20,
      "nodePadding": 20,
      "iterations": 0,
      "laneGap": 10,
      "orientation": "horizontal"
    }
  })
  .createFlowLinks({
    "links": {
      "opacity": 0.55,
      "overrides": [
        {
          "key": "a",
          "fill": "#2563eb"
        },
        {
          "key": "b",
          "fill": "#f59e0b"
        }
      ]
    }
  })
  .createFlowNodes({
    "nodes": {
      "overrides": [
        {
          "key": "Supply A",
          "fill": "#2563eb"
        },
        {
          "key": "Supply B",
          "fill": "#f59e0b"
        },
        {
          "key": "Total",
          "fill": "#0d9488"
        }
      ]
    },
    "labels": {
      "content": "value",
      "fill": "#ffffff",
      "fontSize": 14,
      "fontWeight": 600
    }
  })
  .createTitle({
    "text": "Flow · two sources, one total",
    "subtitle": "Ribbon thickness preserves the explicit source values",
    "align": "left",
    "alongOffset": 0,
    "offset": 2,
    "gap": 8,
    "titleStyle": {
      "color": "#0f172a",
      "fontSize": 20,
      "fontFamily": "sans-serif",
      "fontWeight": 600
    },
    "subtitleStyle": {
      "color": "#64748b",
      "fontSize": 12,
      "fontFamily": "sans-serif",
      "fontWeight": 400
    }
  });
```

Draw links first so node bodies cover the attachments. `balance: "strict"`
checks internal nodes; sources and sinks may have a net flow. A source revision
updates the graph, layout and both marks together, or rejects the entire change
if it would invalidate an endpoint or conservation rule.

For feedback, select `method: "cyclic"`. All edges remain represented, including
self-loops when the flow graph explicitly enables them. Outside lanes are part
of the stored bounds, so fitting and clipping include their full extent.

The [shared example source](https://github.com/ggaction/ggaction/blob/920096cf05fd9a458c5f8c59bafc30e9aa670365/examples/flow-layouts/program.js)
also demonstrates vertical flow and typed per-item colors. The browser example,
primitive comparisons and generated figures use that one program.
See [Flow Data and Sankey Layouts](../../../api/flows/) for exact options, selection
fields, defaults and lifecycle behavior.
