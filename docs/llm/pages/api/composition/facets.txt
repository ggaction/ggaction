# Facets and Field Repetition

[Family overview](../../../../api/composition/) · [Exact action lookup](../../../../reference/actions/)

## Use different horizontal and vertical gaps

A facet can set `gap: { x: 32, y: 48 }` to leave more space between rows than
between columns. The existing number form applies the same gap in both directions.
This complete example preserves one plot per panel:

> **Executable complete.** Import chart from ggaction. This complete program includes all four panel rows and retains the original dataset while creating the facet.

```js
import { chart } from "ggaction";

const program = chart()
  .createCanvas({ width: 240, height: 180 })
  .createData({ values: [
    { panel: "A", x: 1, y: 2 }, { panel: "B", x: 2, y: 3 },
    { panel: "C", x: 3, y: 1 }, { panel: "D", x: 4, y: 4 }
  ] })
  .createScatterPlot({ x: "x", y: "y" })
  .facet({ field: "panel", columns: 2, gap: { x: 32, y: 48 } });
```

Both keys are required, even for a single row or column. Values must be finite and
non-negative; partial objects and unknown keys are rejected. The same pair is
supported by field repetition and row-column grids. Existing spacing rules still
apply: canvas gaps separate child canvases, plot gaps separate data regions, and
content gaps separate retained content. A row-column grid still rejects content
spacing. Titles, headers, guides and legends keep their existing ownership and
collision checks. Concat continues to accept only a number.

## Declare a legend for the complete facet

Pass a legend object to `guides.legend` to create it against the combined inner plots.
This runnable example keeps each child plot 60 pixels wide while its parent legend uses
the 246-pixel union of four plots and three 2-pixel gaps:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```js
import { chart } from "ggaction";

const program = chart()
  .createCanvas({ plot: { width: 60, height: 275 }, margin: { top: 35, right: 5, bottom: 60, left: 45 } })
  .createData({ values: Array.from({ length: 8 }, (_, i) => ({
    x: i, y: i + 1, group: i % 2 ? "B" : "A", panel: String(i % 4)
  })) })
  .createScatterPlot({ x: "x", y: "y", color: "group", guides: false })
  .facet({ field: "panel", columns: 4, spacing: "plot", gap: 2,
    guides: { axes: "outer", legend: { position: "top-left" } } })
  .editLegendTitle({ fontSize: 11 })
  .editLegendLabels({ fontSize: 10 });
```

The object uses ordinary `LegendOptions` defaults. `target` refers to the source mark;
it is inferred only when unique. Child legend styles are independent. Use `"shared"`
to promote or infer the template legend with its existing behavior, and `false` for
no parent shared guide. Child dimensions and margins stay fixed.

Automatic `"shared"` inference keeps continuous or discretized color and stroke
in separate native legend blocks, each using its own scale. Compatible ordinal
channels keep their combined categorical symbols. A mark with numeric color can
also retain an ordinal shape companion. Existing child legend owners keep
their configured styles when promoted.

Existing legend editors, channel/block selectors and removal work on facet, grid and
repeat parents. A missing parent legend can be declared with
`editFacetGuides({ legend: { position: "top-left" } })`. Removing the final block keeps
it absent during later edits. `"shared"` restores template promotion; an object replaces
the parent declaration. `createLegend` remains an action for unit charts.

Corners and free `at` coordinates use the final plot union. Explicit local block anchors
use the same union. Occupied text, symbols and border must fit and clear retained axes,
headers and the chart title. A layout edit that makes the union too small fails without
changing the previous program. Parent styles and automatic title/sample/offset policies
survive data, source, scale, theme, text-metric and layout changes and editable persistence.
Shared appearance scales and compatible source mark recipes are required in every child.

Point-bearing parent legend blocks support `clipHeight` just like unit legends.
Each block retains its own window during layout edits and editable import; a
clipped size block can share its owner with an unclipped color gradient.
Use `editLegendBlock({ target: "scatterPlot", channel: "size", clipHeight: "auto" })`
to remove only the selected block window.

A color-size combination also works on a parent: use `combine: "color-size"`
with `channels: ["color", "size"]` for one Cartesian circle-point source whose
color and size encode the same quantitative field with matching domain endpoints.
The two channels select one combined block. Both scale bindings, samples and
`clipHeight` survive saving, loading and layout edits; removing that block leaves
other parent legend blocks intact.

## Rotate panel headers

Put a region name beside its panel with the existing header editor:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `program`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```js
program.editFacetHeaders({
  role: "column",
  side: "left",
  rotation: { value: -90, unit: "degrees" }
});
```

This is a fragment for an existing facet program. A one-field facet uses the
`column` header role for each panel, including panels arranged in one column.
Grid facets also provide a `row` role. The [complete example](https://github.com/ggaction/ggaction/tree/68873baa2ed1b2c73db31124f8237df3b3cc428f/examples/facet-header-rotation)
declares the axes and grid before arranging the two region panels.

The same `rotation` option is available in common `headers` and in
`headers.row` or `headers.column` during `facet`, `facetGrid` and `repeatCharts`.
A number means radians; the structured form makes the unit explicit. Omission
preserves the current choice, and `0` restores the unrotated layout.

For role headers, `offset` measures the outward gap to the rotated text block;
`align` positions that block along the plot edge. The layout reserves its rotated
width or height. With plot spacing, an outer rotated header uses existing child
margin space before reserving more. Child plots keep their sizes. Text that
crosses the Canvas, another header or a retained guide still fails clearly.
Legacy headers inside child canvases retain their existing anchor when rotated;
increase their margin or offset when the rotated text needs more room.

For an existing facet with plot spacing, the fragment
`program.editFacetHeaders({ anchor: "content" })` moves each header outward when its
marks extend beyond the plot edge. Alignment along the edge still follows the plot.
This uses concrete mark geometry, including strokes and clipping, regardless of
opacity; axes, legends and titles are excluded. The same option works in initial
`headers`, including row and column overrides. Field titles keep their plot anchor.
Omission or `anchor: "plot"` preserves the existing placement. Content anchoring
requires `spacing: "plot"` or `"content"` and sufficient space; it never changes child plot sizes.

## Repeat the current chart by a field

Call `facet` on one complete unit chart to repeat it for each observed field
value:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
import { chart } from "ggaction";

const faceted = chart()
  .createCanvas({ width: 250, height: 230 })
  .createData({ values: cars })
  .createPointMark()
  .encodeX({ field: "Horsepower" })
  .encodeY({ field: "Miles_per_Gallon" })
  .encodePointRadius({ value: 2.5 })
  .encodeColor({ field: "Cylinders", fieldType: "ordinal" })
  .facet({
    field: "Origin",
    columns: 3,
    guides: { legend: "shared" }
  })
  .createTitle({ text: "Horsepower and Fuel Economy" });
```

The input rows in this runnable fragment must contain complete values for the
encoded fields. See the
[repository example](https://github.com/ggaction/ggaction/tree/68873baa2ed1b2c73db31124f8237df3b3cc428f/examples/cars-origin-scatterplot-facet)
for the complete data preparation and guide options.

Data-bound Cartesian text layers also repeat: encode x, y, and text before
faceting. Label data must share the partition ancestor; filters replay per cell.
Reuse the point layer's scale IDs to align labels with its positions. A cell with
no matching label rows retains its other marks.

`facet` uses field values in source first-appearance order. It infers one
common row-preserving dataset ancestor, then filters and replays supported
derived data independently inside each cell. Omitted `columns` creates one row;
a positive value wraps cells row-major. A facet uses the shared 10,000 generated-item limit,
and source-row count multiplied by child count must not exceed the shared
10,000,000-unit work budget.

To facet on a key created by `createFoldData`, pass its materialized dataset ID
explicitly as `data`. Every repeated layer must depend on that fold snapshot.
The original wide rows, fold definition and complete folded table remain intact;
each child filters the folded table, then replays only downstream transforms.
Omitting `data` keeps the usual row-preserving inference. Other statistical
transforms do not become valid partition anchors. `facetGrid` accepts the same
explicit fold boundary. Changing a fold definition creates a new snapshot;
select that snapshot explicitly when creating a new composition.

Explicit tick, label, and grid values are intersected with each cell domain; shared scales restore the source selection.

Final-item `filterMarks` recipes are also evaluated within each partition, after
the target mark has been rebound to that partition. Empty matches preserve
shared-scale panels, and `editFacetSource` can add, replace, or remove the filter.

| Option | Default | Effect |
| --- | --- | --- |
| `id` | `"facet"` | Names the parent and deterministic child namespaces |
| `field` | required | Field in the selected partition dataset whose values define cells |
| `data` | unique common ancestor | Selects a common row-preserving ancestor, or an explicit materialized fold snapshot shared by every layer |
| `values` | source first-appearance order | Selects and orders a non-empty set of observed scalar values |
| `columns` | number of values | Sets the grid column count |
| `gap` | `16` | Sets horizontal and vertical cell spacing |
| `spacing` | `"canvas"` | Measures gaps between child canvases or, with `"plot"`, inner plot tracks; `"content"` independently packs full retained bounds |
| `topLane` | `"stacked"` | With plot spacing, `"shared"` places parent title and top headers in the existing top margin |
| `align` | `"center"` | Aligns unequal cells inside grid tracks |
| `padding` | `0` on every side | Adds scalar or four-side parent padding |
| `scales` | every used role `"shared"` | Sets `"shared"` or `"independent"` per `x`, `y`, `xOffset`, `yOffset`, `theta`, public `r`, `color`, `stroke`, `size`, `shape`, `opacity`, `strokeDash`, or all `parallelDimensions` |
| `headers` | default header style | Common text style/map plus optional `row` and `column` overrides; role objects also accept `side` |
| `guides.axes` | `"each"` | `"outer"` keeps occupied-edge Cartesian x/y axes; `{ x: "outer", y: "each" }` shares only X; Polar and Parallel axes remain local and reject `"outer"` |
| `guides.legend` | `false` | `"shared"` promotes one compatible parent-owned categorical, gradient, discretized-color, size, or opacity legend |

Author the legend position on the unit chart before calling `facet`. Promotion
preserves an explicit `left`, `right`, `top`, or `bottom` edge and the
horizontal `align` used by top and bottom legends; there is no separate facet
legend-position option:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const source = chart()
  .createCanvas({
    width: 420,
    height: 300,
    margin: { top: 40, right: 40, bottom: 90, left: 60 }
  })
  .createData({ values: cars })
  .createPointMark()
  .encodeX({ field: "Horsepower" })
  .encodeY({ field: "Miles_per_Gallon" })
  .encodeColor({ field: "Cylinders", fieldType: "ordinal" })
  .createLegend({
    channels: ["color"],
    position: "bottom",
    direction: "horizontal",
    align: "center"
  });

const facetedWithBottomLegend = source.facet({
  field: "Origin",
  columns: 1,
  guides: { legend: "shared" }
});
```

For a promoted top or bottom legend, the parent reserves a horizontal lane and
keeps the child-grid width unchanged. Left and right legends reserve a vertical
lane instead. If the source has no concrete legend and `facet` infers the
legacy categorical shared legend, the default remains `right`. Subsequent
`editCompositionLayout` calls preserve the promoted edge and alignment.

Shared auto domains use the full faceted result; independent auto domains are
resolved from each cell. An explicit semantic domain always wins. Regression,
density, interval/error-band, and box-summary/outlier datasets are replayed
after the cell filter, so each panel receives a fresh statistical result rather
than a clipped copy of the full-chart result.

The Cartesian slice supports point, line, area, histogram, aggregate bar,
ranged bar, rule, regression, density, interval/error-band, and box-plot layers.
Polar Point, Line, direct Arc, Pie, Rose, and Radar charts and Parallel-coordinate
charts can also be faceted when their visible layers share one valid
row-preserving partition ancestor and one coordinate family. Public scale
policy `r` addresses the semantic radius role; `radius` is not an alias.
`parallelDimensions` applies one policy independently to every dimension scale,
so unrelated units are never merged into one domain. Shared domains do not
share pixel ranges: every Polar frame and Parallel dimension position is
resolved against its child Canvas.

These are fragments that require already-complete unit programs:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `polarUnit`, `parallelUnit`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const radialPanels = polarUnit.facet({
  field: "region",
  scales: { theta: "shared", r: "independent" }
});

const parallelPanels = parallelUnit.facet({
  field: "region",
  scales: { parallelDimensions: "shared" }
});
```

A shared legend is accepted only when every represented child scale and legend
recipe is concretely compatible; scale resolution alone does not make a guide
shareable. Polar theta/radius axes and Parallel dimension axes remain inside
each panel. Requesting outer axes for either family fails before a composition
is returned.

Create a chart title after `facet` so the title is owned directly by the
parent. A title that already fits the unit Canvas is promoted for authoring
order compatibility rather than repeated in every cell.

The parent title aligns to the union of the child plot bounds, excluding cell
margins and the shared legend. Each repeated header is likewise centered on
its own child plot—not on the complete child Canvas—so asymmetric axis space
does not visually offset panel titles.

Edit the repeated header style without addressing generated graphic IDs:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `faceted`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const emphasized = faceted.editFacetHeaders({
  fontSize: 13,
  fontWeight: 700,
  color: "#0f172a",
  offset: 10
});
```

Facet-header weights follow the shared
[Canvas font-weight policy](../../../../api/marks/text/#font-weights).

An unqualified edit updates the common header style and keeps the existing
one-header-per-cell layout. A row or column role switches to separate strips:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const labeledMatrix = matrix
  .editFacetHeaders({
    labelMap: [{ value: "Q1", label: "First quarter" }]
  })
  .editFacetHeaders({
    role: "row",
    side: "left",
    align: "center",
    labelMap: [{ value: "North", label: "Northern region" }]
  })
  .editFacetHeaders({
    role: "column",
    side: "bottom",
    align: "start"
  });
```

Row-column grids create one header for each occupied column, followed by one
for each occupied row. One-field facets and `repeatCharts` support the column
role and retain one header per cell. Supported sides depend on the facet topology:

| Facet topology and role | Supported sides |
| --- | --- |
| Row-column grid, row headers | `left`, `right` |
| Row-column grid, column headers | `top`, `bottom` |
| One-field facet or repeat, column headers | `top`, `bottom`, `left`, `right` |

For one-field facets, `editFacetHeaders({ role: "column", side: "right" })`
places each value beside its own panel. Left/right headers reserve measured
width for every physical column, including wrapped grids with zero gap or
padding. Child plot sizes stay unchanged. `align` follows the vertical plot
span on the sides and the horizontal plot span at the top/bottom.
Role settings override the common style and map.
`labelMap: "auto"` on a role returns to the common map, while an unqualified
reset returns to the normal visible formatter. Typed raw values remain the
partition identity. Duplicate display text and `""` are allowed; an empty
mapped header keeps its stable item position and reserves no strip space.

Header strips are measured before child placement. Changes to fonts, labels,
sides, composition layout, titles, or shared legends therefore rebuild the
required parent space without moving or rewriting child program identity.

A complete example with a right-side header for each panel:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
import { chart } from "ggaction";

const panels = chart()
  .createCanvas({ width: 200, height: 160, margin: 35 })
  .createData({ values: [
    { panel: "First", category: "A", value: 2 },
    { panel: "Second", category: "A", value: 5 }
  ] })
  .createBarPlot({ x: "category", y: "value", guides: false })
  .facet({ field: "panel", columns: 2, gap: 0, padding: 0 })
  .editFacetHeaders({ role: "column", side: "right" });
```

## Build a row and column facet grid

Use `facetGrid` when two source fields define the comparison:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `unit`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const matrix = unit.facetGrid({
  id: "matrix",
  rows: { field: "region", values: ["North", "South"] },
  columns: { field: "period", values: ["Q1", "Q2", "Q3"] },
  combinations: "full",
  gap: 12
});
```

Omitted row or column `values` use source first-appearance order. `"observed"`
creates children only for pairs present in the source while retaining each
pair's actual grid coordinates. `"full"` creates the Cartesian
product. A missing pair remains a named Canvas with its semantic layers,
coordinate, canonical empty graphics, and header, so neighboring cells never
shift into its position. Shared domains are inferred from populated cells and
allow the empty child to materialize local axes or grids. An independent
automatic domain with no final values is an error; an explicit domain is valid.

The child limit is 100 after applying the combination policy. The same
10,000,000-unit partition-work limit used by `facet` applies. `facetGrid`
supports the same Cartesian, Polar, and Parallel chart families, scale policies,
axis restrictions, and compatible shared legends as `facet`.

See the [runnable grid example](https://github.com/ggaction/ggaction/tree/68873baa2ed1b2c73db31124f8237df3b3cc428f/examples/facet-grid)
for a 2 × 3 full grid with one missing source pair.

## Repeat a positional encoding across fields

`repeatCharts` accepts direct materialized lookup and computed datasets as well as
ordinary source data. It changes the selected encoding field without rewriting
expressions or lookup inputs. A parent `editParameter` rebuilds repeated children
from the retained source when a repeated computed field depends on that parameter.

`repeatCharts` compares several fields without copying the complete unit recipe:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `unit`. Resource selectors used here: `target: "product"`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const metrics = unit.repeatCharts({
  id: "metrics",
  target: "product",
  channel: "x",
  fields: ["speed", "quality", "cost"],
  columns: 3,
  guides: { legend: "shared" }
});
```

The action accepts `x` or `y` on one direct Cartesian mark, `theta` or public
`r` on eligible Polar Point/Line/direct Arc/Rose roles, and one
`{ parallelDimension: field }` on Parallel coordinates. The Parallel form
replaces exactly one dimension and preserves its position, field type, explicit
title, sibling dimensions, row key, and missing-value policy. `target` may be
omitted only when exactly one primary mark is eligible. Attached labels and
statistical-reference dependents owned by that target replay with it. Child IDs
and headers follow the ordered field list.

This fragment requires a complete Parallel-coordinate unit:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Caller-provided receivers: `parallelUnit`. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```javascript
const comparisons = parallelUnit.repeatCharts({
  channel: { parallelDimension: "horsepower" },
  fields: ["horsepower", "weight", "displacement"]
});
```

The repeated role defaults to independent domains; requesting it as shared
produces the union domain. Other used roles default to shared, and one compatible
non-repeated legend may be promoted to the parent.

Every repeated field can describe a different quantity, so outer-axis
promotion is rejected. Pie and Radar raw theta/r repetition, composite roles,
derived target datasets, and unrelated sibling layers also fail atomically.
See the [runnable repeat example](https://github.com/ggaction/ggaction/tree/68873baa2ed1b2c73db31124f8237df3b3cc428f/examples/repeat-charts).

## Space between plots

Use `facet({ field: "group", spacing: "plot", gap: 5 })` when the five-pixel gap
should separate the data regions. The default `"canvas"` mode includes both
children's margins between those regions. Plot mode retains each data region's
size and reserves child margins once around the outer grid. Panel backgrounds
cover their plots; the parent background covers the surrounding area.

The same option works with `facetGrid`, `repeatCharts`, and facet
`editCompositionLayout`. Headers and retained guides must fit the specified gap;
otherwise the action reports a collision. `guides: { axes: "outer" }` removes
interior axes, but remaining edge labels still need enough space. Increasing the
gap or changing guide/header settings resolves those collisions without changing
panel dimensions.

## Share the existing top margin

With plot spacing, `topLane: "shared"` lets the parent title and top headers use the
existing child top margin and parent padding. The default `"stacked"` reserves their
height separately. This complete program retains seven 40 × 200 plots inside a
508 × 262 Canvas, including the upper Y-axis endpoint:

> **Contextual fragment.** Use an ES module with the imports, data, and prepared resource state described in this section. Resolve these names from setup in this fragment or section; alternatives branch from the same base.

```js
import { chart } from "ggaction";

export const days = ['Sun','Mon','Tue','Wed','Thu','Fri','Sat'];
export const rows = days.flatMap(panel => [{panel,group:'a',value:13},{panel,group:'b',value:14}]);

export function createFacetLaneUnit() {
  return chart().createCanvas({width:136,height:262,margin:{left:40,right:56,top:43,bottom:19}})
    .createData({values:rows})
    .createBarPlot({x:'group',y:{field:'value',scale:{domain:[0,50],nice:false}},guides:false})
    .encodeColor({field:'group',layout:'overlay'})
    .createAxes({x:{title:false,ticksAndLabels:{labels:{fontSize:10,color:'black',offset:5.5}}},
      y:{ticksAndLabels:{values:[0,10,20,30,40,50],labels:{fontSize:10,color:'black',alongOffset:.890625}},title:false}})
    .createLegend({title:'group',titleStyle:{fontSize:10},labels:{fontSize:10}});
}

export function createFacetSharedTopLaneProgram() {
  return createFacetLaneUnit().facet({field:'panel',values:days})
    .editFacetGuides({axes:'outer',legend:'shared'})
    .editCompositionLayout({spacing:'plot',gap:22})
    .editFacetHeaders({fontSize:10,fontWeight:400,offset:10.609375})
    .createTitle({text:'Grouped Bar Chart',align:'left',offset:-2.953125,
      titleStyle:{fontSize:13,fontWeight:700,color:'black'}})
    .editCompositionLayout({topLane:"shared"});
}

const program = createFacetSharedTopLaneProgram();
```

The same option works at facet, grid and repeat creation or in
`editCompositionLayout`. Text must fit and clear the plots and retained labels;
insufficient space reports a collision. Adjust explicit padding, title or header
settings to make space. The action keeps child dimensions and font sizes.

Omitting the option in an edit preserves it. Reset with
`editCompositionLayout({ topLane: "stacked" })`. To switch back to Canvas spacing,
reset both together: `editCompositionLayout({ spacing: "canvas", topLane: "stacked" })`.
Concat compositions reject this option. Shared legend placement keeps its existing
edge, offset and occupied bounds.

## Name the complete facet field

Panel names identify individual values; a field title names what all panels share.
Use the complete runnable example linked above.
Create a title through `headers.column.title`, or edit a prepared facet with
`editFacetHeaders({ role: "column", title: { text: "Region" } })`. Grids also support
`role: "row"`. Repeats require an explicit title text, just like ordinary facets.

A field title appears once across the union of occupied plots, including wrapped
or sparse layouts. It is independent of `createTitle`. Its font inherits the role
header unless overridden. Initial creation requires nonempty one-line `text`;
later title objects merge their changes. `title: false` removes the role title.
Common headers and `role: "all"` cannot own a title.

Title options are `text`, `fontSize`, `fontFamily`, `fontWeight`, `color`, `offset`,
`align`, `rotation`, and `alongOffset`. Alignment defaults to `"center"`, with
`"start"` and `"end"` also available. Rotation defaults to horizontal on top/bottom,
−90° on the left and +90° on the right; explicit rotations use the usual radians
or `{ value, unit }` form. `alongOffset` shifts along that edge.

The title's `offset` measures the distance to its nearest rotated ink edge from
the plot union with plot spacing, or the occupied child Canvas union with Canvas
spacing. The default clears same-side category headers and retained child margins
by 8 pixels. An explicit offset preserves that requested distance. Existing outer
margin and header space is reused once; only the remaining title lane is reserved.
Titles must fit without overlapping panel headers, plots or retained chart text.
A conflicting edit fails atomically. Omitting all title options preserves existing
charts exactly, and source, layout, theme, font metrics and saved editable programs
retain the field-title owner.

## Independently packed panels

For an existing Cartesian program with axes, this fragment packs complete visible panel
bounds while keeping every Y axis and one common bottom X footer per occupied column:

Use `program.facet({ field: "group", columns: 2, spacing: "content", gap: 16,
headers: { anchor: "view" }, guides: { axes: { x: "outer", y: "each" } } })`.
The program must already contain a `group` field and Cartesian mark encodings.

Panel plot sizes and logical group order stay fixed. Different axis labels or mark overflow
can give panels in the same logical row different plot origins. `gap` adds clearance between
measured content bounds. The parent Canvas includes the final footer, title and legend lanes.
The full-body `view` header anchor includes retained guides; `content` continues to measure
marks and the plot only. Both anchors accept plot or content spacing.

Use content spacing with wrapped `facet` or `repeatCharts`. Keyed `facetGrid` retains aligned
tracks and rejects it. Shared top lanes require plot spacing. Repeat keeps axes local and
rejects any `outer` channel. Per-channel policies require Cartesian coordinates.
`align` controls slots in canvas/plot spacing; content flow uses independent measured bounds.
