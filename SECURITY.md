# Security Policy

## Supported versions

Security fixes are provided for the latest published ggaction version. Upgrade to the current npm `latest` release before
reporting a problem that only affects an older version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/ggaction/ggaction/security/advisories/new) and include:

- the affected ggaction version and package entry point;
- the runtime and operating system;
- the smallest reproduction that demonstrates the impact;
- the expected and actual security boundary; and
- any known workaround or disclosure deadline.

Do not include unrelated private data, credentials, or production datasets. You should receive an acknowledgement within
seven days. We will investigate, coordinate a fix and release, and credit the reporter unless anonymity is requested.

## Scope

Security reports may cover the published package, renderer adapters, generated SVG/PDF/PNG output, documentation site,
release workflow, dependency boundary, or a demonstrated denial-of-service input. Ordinary rendering bugs and feature
requests belong in the public issue tracker.
